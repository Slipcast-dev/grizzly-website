"""Small demo for syntax highlighting."""
from dataclasses import dataclass

@dataclass
class Task:
    title: str
    done: bool = False

def summary(tasks: list[Task]) -> str:
    finished = sum(1 for t in tasks if t.done)
    return f"{finished}/{len(tasks)} done"

tasks = [Task("write docs", True)]
print(summary(tasks))

Что умеет Grizzly

Grizzly — редактор Markdown, текста и кода. Подсветка синтаксиса, вкладки, два файла рядом, поиск, теги и проверка орфографии RU/EN. В macOS — режимы «Пользователь» и «Разработчик», форматирование и вложения. Файлы хранятся локально.

Новые режимы, форматирование и вложения v1.3.0 доступны в macOS. В Windows пока сохранён набор функций v1.2.2.
